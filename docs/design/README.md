# 디자인 시안 사본

원본은 Claude 디자인 캔버스에 있어요. 여기 있는 `.dc.html`은 기록용 사본이라 이미지(`/_blob/...`)가 이 저장소에서는 보이지 않아요.

## 앱 이름: 눈맞춤 (구 '누구의 눈')

- '누구의 눈'은 "누구 눈일까?" 하는 퀴즈처럼 읽혀서, 사랑하는 아이·반려동물이 나를 본다는 감정이 약했어요.
- '눈맞춤'은 아기와 반려동물이 눈을 맞추는 장면을 떠올리게 해요. 짧아서 토스 목록에서도 눈에 띄어요.
- 영문 표기는 필요할 때만 'Eye to Eye'를 써요. 같은 이름의 퀴즈 앱과 미국 비영리단체가 있어서 단독 이름으로는 쓰지 않아요.
- 중복 확인 (2026-11-11)
  - 한국 앱스토어: 같은 이름의 앱 없음
  - 상표(키프리스 제9·42류): 아직 확인 전
  - 앱인토스 콘솔: 등록할 때 확인
- 저장소 주소(`nugu-eye`)는 배포 주소가 바뀌지 않게 그대로 둬요.

## 확정: E안 "우리 가족 눈에 비친 나"

이 앱을 만든 이유는 "내가 사랑하는 아이나 반려동물이 나를 어떻게 보는지 궁금해서"예요. 결과 카드도 이 질문에 답하게 만들었어요.

- 카드 주인공은 장면이 아니라 **나**예요. 내 얼굴 사진 한 장을 줄마다 반반으로 나눠요. 왼쪽은 내 눈, 오른쪽은 가족의 눈이에요.
- 줄 아래에는 **그 아이 목소리**로 한 줄을 써요. 앱 문구 규칙에 맞춰 해요체예요.
  - 아기: "세상은 아직 흐릿한데, 엄마 얼굴은 보여요" (12개월: "이제 엄마 얼굴이 꽤 또렷하게 보여요")
  - 강아지: "색은 잘 몰라도, 웃는 얼굴은 알아봐요"
  - 고양이: "불을 꺼도, 엄마는 내가 제일 잘 찾아요"
- 결과 화면에서 가족마다 이름을 넣을 수 있어요(선택). 이름은 저장하지 않아요. 한 명만 남기면 제목이 "콩이 눈에 비친 나"처럼 바뀌어요.
- "가족이 나를 부르는 말"은 지금 엄마·아빠 두 가지예요.

| 안 | 내용 | 결과 |
|---|---|---|
| A | 2×2 + 칸별 한 줄 | 보류 |
| B | 원래 모습 크게 + 3컷 | 보류 |
| C | 반반 비교 실사 | 흰 강아지·회색 고양이 사진이라 색 변화가 안 보이고 흐림만 남았어요 |
| D | 색 있는 장면 + 강점(고양이 밤눈 등) | 차이는 잘 보이지만 '나'가 없어서 감정이 약했어요 |
| **E** | 내 얼굴 + 그 아이 목소리 + 이름 | **확정** |

## 같이 바뀐 화면

- 시작: 결과 예시(`assets/ex-*.jpg`)를 그대로 눈 고르기 목록으로 써요.
- 카메라: 앞 카메라로 시작해요. 반반 보기는 아기까지 넓혔고, 화면을 끌면 비교선이 따라와요. 설명 칸 위에 시력 수치 한 줄을 넣었어요.
- 카메라 아래 찍는 법 안내:
  - 아기: "아이를 안았을 때처럼 20~30cm 앞에서"
  - 강아지·고양이: "바닥 가까이에서 올려다보며"
- 엔진 흐림 보정 `BOOST`는 4에서 2로 낮췄어요. 흐림보다 색과 밝기 차이가 보이게 하려는 거예요.

## 남은 일

- 대표색 미정. `Brand.dc.html`에 후보 3개(토스 파랑·해바라기 노랑·인디고)가 있어요.
- 카드 문구의 근거를 설명 시트 출처와 맞추기: 신생아 초점 거리 20~30cm, 개의 사람 표정 구분(Müller 외 2015), 고양이 저조도 시력.
- 반반 분할선은 사진 가운데에 고정돼 있어요. 얼굴이 한쪽에 치우친 사진은 "내 눈" 쪽에 얼굴이 안 나올 수 있어요. 셀카는 대부분 가운데라 1차는 그대로 두고, 필요하면 얼굴 위치를 찾아 맞춰요.
- 실기기(토스 웹뷰 iOS·안드로이드)에서 카메라와 비교선 끌기 확인.
